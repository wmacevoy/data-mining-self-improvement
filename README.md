# data-mining-self-improvement

The work that makes the [DM1 guide](https://github.com/wmacevoy/data-mining) better, kept out of it. The guide stays easy to vendor
and to trim; nothing learned on the way is lost.

- `trials/`: one directory per trial: what was asked, what would count against the claim, the harness, the raw transcripts,
  and the results. Data that a seeded generator makes is not kept.
- `quickref/`: drafts of the guide's quick reference.
- `sandbox/`: a wrapper that keeps a trial's unattended session from your home directory.

What a trial finds goes back to the guide only as a conclusion that changes something: `GAPS.md` when it bears on a principle, `docs/FINDINGS.md`
when it bears on the guide's own work, each with a link here and a commit.
